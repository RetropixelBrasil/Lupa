# 🔎 Lupa™

**Lupa™** é um portal de pesquisa retrô desenvolvido pela **Retropixel™**, inspirado nos grandes portais da Web dos anos 90 e 2000, como Yahoo!, MSN Search, AltaVista e Lycos.

Seu objetivo é oferecer uma página inicial simples, rápida e nostálgica para navegar na Internet, combinando o visual clássico da Web 1.0 com recursos modernos.

---

## ✨ Recursos

* 🔎 Pesquisa na Web
* ⭐ Favoritos
* 🕘 Histórico de pesquisas
* 📄 Pesquisas recentes
* 🌐 Links rápidos
* 📚 Página de ajuda
* 🔒 Política de privacidade
* 📜 Termos de uso
* ℹ️ Página "Sobre"

---

## 🖥️ Tecnologias

## 📌 Objetivos

O Lupa™ busca proporcionar uma experiência simples e agradável para quem aprecia o visual clássico da Internet, funcionando como um portal de pesquisa independente e podendo ser utilizado como página inicial de qualquer navegador.
