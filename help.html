Bem-vindo ao Lupa™

O Lupa™ é um portal de pesquisa desenvolvido pela Retropixel™. Esta página reúne dicas para aproveitar melhor os recursos disponíveis.

Como pesquisar

  1. Digite uma palavra ou frase na caixa de pesquisa.
  2. Clique em Pesquisar ou pressione Enter.
  3. Os resultados serão exibidos pelo mecanismo de busca configurado.

Dicas de pesquisa

  • Use palavras específicas para obter resultados mais precisos.
  • Pesquise por frases completas quando necessário.
  • Coloque uma expressão entre aspas para procurar exatamente aquele texto.
  • Experimente diferentes palavras caso não encontre o que procura.
  • Evite palavras desnecessárias.

Links rápidos

A página inicial oferece atalhos para diversos serviços, como:

  • Notícias
  • Imagens
  • Mapas
  • E-mail
  • Tradutor
  • Clima
  • Dicionário

Favoritos

Os favoritos permitirão guardar seus sites preferidos para acesso rápido diretamente pela página inicial.

Histórico

O Lupa™ mantém uma lista das pesquisas recentes para facilitar novas consultas.

Configurações

Nas configurações você poderá escolher:

  • Mecanismo de pesquisa padrão.
  • Tema claro ou escuro.
  • Abrir pesquisas na mesma aba ou em uma nova aba.

Compatibilidade

O Lupa™ foi desenvolvido para funcionar em navegadores modernos e também servir de base para uma versão compatível com navegadores clássicos da Web.
